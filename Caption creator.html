How to Use in After Effects

100% Automated Setup via ExtendScript

Method 1: One-Click .JSX Script (Recommended)

  1. Click Download AE Script (.jsx) in the right panel.
  2. In After Effects, open your composition (e.g. 1080x1920).
  3. Choose File > Scripts > Run Script File... and select the downloaded file.
  4. The script automatically creates the text layer, fills, outside stroke, word animator, range selector (words/index), and the parented vector background box.

Method 2: Manual Copy & Paste

  1. Create a Text Layer and Alt-click Source Text. Paste code 1.
  2. Add Text Animator > Fill Color > RGB.
  3. In Range Selector > Advanced, set Units = Index and Based On = Words.
  4. Alt-click Start and paste code 2. Alt-click End and paste code 3.
